# LeetCode Clone GitHub Pages

A polished frontend clone of a coding practice platform inspired by LeetCode. Built with only HTML, CSS, and JavaScript, this project is designed for GitHub Pages deployment and includes a complete set of UI screens, interactions, and responsive styling.

## Project Overview

This repository contains a full frontend experience for a LeetCode-inspired clone. It includes:

- A modern landing page with hero content and trending problem cards.
- Authentication interface with login and signup forms.
- Problems page with search, filters, difficulty badges, and acceptance rates.
- Profile page with user statistics, skills, recent activity, and contribution heatmap.
- Contest page with upcoming and past contest cards.
- Dark-mode glassmorphism styling and responsive mobile layout.

## Features

- Responsive navigation and mobile menu
- Dynamic problem filtering and search
- JavaScript form validation and animated tab switching
- GitHub-style heatmap with 365 generated cells
- Dashboard metrics for solved problems and streak tracking
- Professional dark UI with smooth transitions

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## GitHub Pages Deployment Steps

1. Push this repository to GitHub.
2. In the GitHub repository, go to `Settings` -> `Pages`.
3. Choose the `main` branch and root directory `/` as the deployment source.
4. Save the settings.
5. Visit the published URL shown by GitHub Pages.

> Since this project is frontend-only, it is fully compatible with GitHub Pages and requires no backend.
